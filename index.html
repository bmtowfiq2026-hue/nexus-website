Everything You Need to Build AI Agents

Nexus combines the channel breadth of OpenClaw with the self-improving learning loop of Hermes Agent, adding unique innovations like graph memory, DID-based identity, and privacy-as-config.

Self-Improving Learning Loop

Every interaction is recorded as a trajectory. When a task succeeds, Nexus creates a reusable skill. When it fails, the skill is refined with recovery instructions.

Three-Layer Memory

Full-text search (SQLite + Tantivy) for keyword retrieval, vector embeddings for semantic similarity, and graph memory for entity-relation knowledge across sessions.

Checkpoint & Rollback

Every agent turn creates a snapshot. Roll back to any point in time, diff between states, or recover from failures instantly.

13-Channel Gateway

Connect to Discord, Telegram, Slack, WebChat, Matrix, IRC, WhatsApp, Signal, Google Chat, MSTeams, LINE, Messenger, or Twilio via the Go gateway. Message bus architecture for scalable, distributed deployment.

Security & Privacy

Sandboxed execution with configurable resource limits. Local-first data storage. API key protection with masking. Four privacy modes: Air-gapped, Local-first, Selective, Full.

Tool System

Five built-in tools the agent invokes autonomously: read/write files, web search (DuckDuckGo/SerpAPI/Tavily), fetch web pages, and sandboxed command execution.

Get Started in 30 Seconds

No API keys. No accounts. No cloud signup. Just clone, build, and chat.

macOS / Linux

# Clone & install
$ git clone https://github.com/bmtowfiq2026-hue/Nexus.git ~/.nexus-repo
$ bash ~/.nexus-repo/scripts/install.sh

# Start chatting
$ nexus chat

Windows PowerShell

# Clone & install
PS> git clone https://github.com/bmtowfiq2026-hue/Nexus.git $env:USERPROFILE\.nexus-repo
PS> & "$env:USERPROFILE\.nexus-repo\scripts\install.ps1"

# Start chatting
PS> nexus chat
Zero setup. No API keys. No accounts. Works on Windows, macOS, and Linux.
